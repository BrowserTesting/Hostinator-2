Równania kwadratowe — rozwiązanie krok po kroku

Dział: Algebra · Poziom: liceum · Publikacja: 18.06.2026

  • Zobacz rozwiązanie

Jak rozwiązać równanie kwadratowe?

Równanie kwadratowe to równanie postaci ax² + bx + c = 0, gdzie a ≠ 0. Aby je rozwiązać, w pierwszym kroku obliczamy wyróżnik (deltę) ze wzoru:

Δ = b² − 4ac

Jeżeli Δ > 0, równanie ma dwa różne rozwiązania, które obliczamy ze wzoru:

x = (−b ± √Δ) / a

Przykład

Rozwiążmy równanie: x² − 5x + 6 = 0

Współczynniki: a = 1, b = −5, c = 6.

Obliczamy deltę:

Δ = (−5)² − 4·1·6 = 25 − 24 = 1

Skoro Δ = 1 > 0, mamy dwa rozwiązania:

x₁ = (5 + 1) / 1 = 6

x₂ = (5 − 1) / 1 = 4

Odpowiedź: rozwiązaniami równania są x₁ = 6 oraz x₂ = 4.
