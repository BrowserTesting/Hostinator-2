Release Notes — v3.4

This release focuses on performance improvements across large boards and a redesigned notification center. Below is the full changelog for this version, including an internal engineering note kept for audit purposes.

  • Board rendering is now up to 40% faster for projects with 500+ tasks.
  • Notifications can now be grouped by project instead of by date.
  • Fixed a bug where recurring tasks would duplicate after a timezone change.

Next release (v3.5) is scheduled for public beta in six weeks and will include a public API for custom integrations.
